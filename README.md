### 🌙 日有回响 · DayEcho

**从 Deadline 倒推，每天只做好今天这一份。**

大多数待办软件从「今天」往后排；日有回响反过来，先看截止日期，再倒推出**今天至少要做多少**。走到了这条线，今天就可以安心收工；没走到，少做的部分会自动摊到后面的日子，明天不会突然崩掉。

👉 **[打开网站 riyouhuixiang.com](https://riyouhuixiang.com)**（手机、电脑都能用，可添加到桌面，免费）
